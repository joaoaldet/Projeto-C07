## Tema

**Biblioteca**

## Descrição do tema

O projeto representa o banco de dados de uma biblioteca. O sistema permite cadastrar usuários, suas carteirinhas, livros, categorias e autores, além de registrar os empréstimos realizados pelos usuários.
